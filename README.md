# Importaciones Korean - Ropa Coreana Premium

![Estado](https://img.shields.io/badge/Estado-En%20Desarrollo-blue)

## 📝 Descripción
Importaciones Korean es una plataforma de comercio electrónico dedicada a la moda asiática. El proyecto se centra en ofrecer prendas exclusivas con un diseño minimalista, funcional y moderno, trayendo lo mejor de las tendencias de Seúl al mercado digital.

## 🚀 Fase actual: Taller #4
- Configuración de repositorio profesional.
- Maquetación base con React y Vite.
- Documentación estratégica para desarrollo asistido por IA.

## 🛠️ Cómo ejecutar el proyecto
1. Clonar el repositorio.
2. Instalar dependencias con `npm install`.
3. Ejecutar localmente con `npm run dev`.

## 📂 Estructura
- `/assets`: Imágenes de las colecciones y logos.
- `/docs`: Guías de estilo y requerimientos.
