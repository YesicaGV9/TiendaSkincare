# Alcance del Proyecto: Importaciones Korean

**Misión:** Crear la tienda virtual líder en moda coreana premium.

**Funcionalidades Clave:**
- Catálogo de ropa organizado por categorías (Tops, Bottoms, Outerwear).
- Interfaz de usuario inspirada en el minimalismo estético coreano.
- Carrito de compras funcional (Fase futura).
- Diseño responsivo para compras desde dispositivos móviles.

**Público:** Entusiastas de la moda "K-Style" que buscan calidad y diseños vanguardistas.
